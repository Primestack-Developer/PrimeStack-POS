# ⭐ Step 55 — SoftPOS Compliance (PCI CPoC)

---

To launch Tap to Pay, you must meet PCI CPoC requirements:

---

## ✔ 1. Device Security

- Android 10+
- Hardware‑backed keystore
- NFC secure mode

---

## ✔ 2. App Security

- Code obfuscation
- Root detection
- Debug detection
- Anti‑tamper

---

## ✔ 3. Data Security

- No PAN storage
- EMV token only
- HMAC signing
- TLS enforced

---

## ✔ 4. Monitoring

- Fraud engine
- Risk scoring
- Logging

---

## ✔ 5. Certification

- Lab testing
- Documentation
- Annual audit
