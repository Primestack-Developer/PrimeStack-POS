# ⭐ Step 53 — Merchant Onboarding Portal

---

This is the portal merchants use to:

- Register
- Add terminals
- View transactions
- Download settlement reports
- Manage webhooks

---

## 📌 Portal Pages

### 1. Login
- Email
- Password
- MFA

### 2. Dashboard
- Total sales
- Approved/declined
- Settlement summary
- Fraud alerts

### 3. Terminals
- Add terminal
- View secret key
- Activate/deactivate

### 4. Transactions
- List
- Filters
- Export CSV

### 5. Settlement
- Daily
- Weekly
- Monthly
- Download reports

### 6. Webhooks
- Add webhook URL
- Test webhook

### 7. Profile
- Merchant info
- Bank details
- Contact info
