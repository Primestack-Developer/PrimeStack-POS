
# Start PrimeStack Batch File

## Usage
Just double‑click `Start PrimeStack.bat` to start everything!

## What It Does
1. Plays a startup beep
2. Starts backend server at http://localhost:4000
3. Starts dashboard server at http://localhost:3001
4. Automatically opens dashboard in your default browser
5. Plays a success tone when ready

## Prerequisites
- Make sure **MongoDB** is running locally
- Node.js installed
- npm installed
- Dashboard dependencies may take time to install on first run!

## Notes
- Backend runs in a separate cmd window
- Dashboard runs in a separate cmd window
- To stop, close both windows or press `Ctrl+C` in each
